# MIT 控制参数说明

## 📊 官方推荐参数（标准 Piper）

根据研发团队建议，标准 Piper 机械臂的 MIT 控制参数如下：

### 关节分组参数

| 关节组 | Kp（位置增益） | Kd（速度增益） | 说明 |
|--------|---------------|---------------|------|
| **关节 1-3** | 5.5 | 0.35 | 基座、大臂关节 |
| **关节 4-6** | 10.0 | 0.8 | 小臂、腕部关节 |

### 期望速度 (v_des)

- **推荐值**: `v_des = 0`
- **原理**: 期望速度为 0 相当于**阻尼模式**，让电机往目标运动时有一个反向的阻尼，会更稳定地达到目标
- **注意**: 如果 `v_des ≠ 0`，都是正向的相当于没有阻尼，需要规划好每个轨迹点对应的关节位置和速度

## 🔧 配置文件设置

在 `config/blue_tissue_grasp_config.yaml` 中已按照官方推荐值配置：

```yaml
control:
  mit_params:
    compliant:      # 柔顺模式（官方推荐值）
      kp_123: 5.5   # 关节1-3位置增益
      kd_123: 0.35  # 关节1-3速度增益
      kp_456: 10.0  # 关节4-6位置增益
      kd_456: 0.8   # 关节4-6速度增益
    
    stiff:          # 刚性模式（快速运动）
      kp_123: 10.0
      kd_123: 0.5
      kp_456: 20.0
      kd_456: 1.2
    
    damping:        # 阻尼模式（接触保护）
      kp_123: 3.0
      kd_123: 0.3
      kp_456: 5.0
      kd_456: 0.6
  
  # 速度控制模式
  use_velocity_control: false  # false=v_des固定为0（推荐）
```

## 📐 参数含义

### Kp (位置增益/刚度)
- **作用**: 控制关节的"硬度"
- **越大**: 关节越"硬"，位置跟踪越准确，但可能震荡
- **越小**: 关节越"软"，更易被外力推动，柔顺性好

**为什么关节 4-6 的 Kp 更大？**
- 关节 4-6（小臂和腕部）质量更轻，负载更小
- 需要更高的刚度来保持姿态精度
- 更大的 Kp 可以更快地响应位置变化

### Kd (速度增益/阻尼)
- **作用**: 控制关节运动的"平滑度"
- **越大**: 运动越平滑，震荡越少，但响应变慢
- **越小**: 响应更快，但可能震荡

**为什么关节 4-6 的 Kd 更大？**
- 配合更高的 Kp，需要更大的阻尼来抑制震荡
- 保证小臂和腕部的运动平滑

## 🎯 三种控制模式

### 1. Compliant（柔顺模式）- 推荐用于抓取

**使用场景**:
- 接近目标物体
- 柔顺下降
- 需要接触力控制的场景

**特点**:
- 使用官方推荐参数
- 最稳定，最安全
- 适合与环境交互

### 2. Stiff（刚性模式）- 用于快速运动

**使用场景**:
- 远离障碍物的快速运动
- 需要高精度定位

**特点**:
- Kp 增大约 2 倍
- 响应更快，精度更高
- 适合自由空间运动

### 3. Damping（阻尼模式）- 用于接触保护

**使用场景**:
- 可能发生碰撞的情况
- 探索未知环境
- 安全性要求极高的场景

**特点**:
- Kp 降低，关节更"软"
- 受到外力时更容易让步
- 最大限度保护机械臂

## 🔄 速度控制说明

### 模式 1: v_des = 0（阻尼模式，推荐）

```yaml
use_velocity_control: false
```

**工作原理**:
```
期望速度 = 0
实际速度 = v

阻尼力 = Kd × (0 - v) = -Kd × v
```

当机械臂向目标运动时：
- 速度 v > 0 → 阻尼力 < 0（反向阻尼）
- 自动减速，平稳到达目标
- 无需规划速度轨迹

**优点**:
- ✅ 更稳定
- ✅ 实现简单
- ✅ 不需要速度规划

**缺点**:
- ⚠️ 运动速度较慢
- ⚠️ 不适合高速运动

### 模式 2: v_des ≠ 0（速度跟踪模式）

```yaml
use_velocity_control: true
```

**要求**:
- 必须规划每个轨迹点的位置和速度
- 速度通过位置对时间微分得到：`v = dp/dt`
- 需要保证速度连续性

**适用场景**:
- 高速精确轨迹跟踪
- 需要控制运动速度曲线
- 有完整的轨迹规划器

**实现复杂度**: ⭐⭐⭐⭐⭐ (高)

## 🧪 参数调优指南

### 问题 1: 机械臂震荡

**现象**: 关节来回晃动，无法稳定

**解决方案**:
```yaml
# 降低 Kp，增大 Kd
compliant:
  kp_123: 3.0    # 从 5.5 降到 3.0
  kd_123: 0.5    # 从 0.35 增到 0.5
  kp_456: 6.0    # 从 10.0 降到 6.0
  kd_456: 1.2    # 从 0.8 增到 1.2
```

### 问题 2: 响应太慢

**现象**: 机械臂运动缓慢，跟不上指令

**解决方案**:
```yaml
# 增大 Kp
compliant:
  kp_123: 8.0    # 从 5.5 增到 8.0
  kp_456: 15.0   # 从 10.0 增到 15.0
```

### 问题 3: 柔顺度不够

**现象**: 接触力太大，无法柔顺接触

**解决方案**:
```yaml
# 降低 Kp
compliant:
  kp_123: 3.0    # 从 5.5 降到 3.0
  kp_456: 5.0    # 从 10.0 降到 5.0
```

### 问题 4: 无法到达目标位置

**现象**: 停在目标位置附近，有静差

**解决方案**:
```yaml
# 增大 Kp
compliant:
  kp_123: 8.0    # 增大位置增益
  kp_456: 15.0
```

## 📈 参数调优流程

```
1. 从官方推荐值开始
   └─> kp_123=5.5, kd_123=0.35, kp_456=10.0, kd_456=0.8

2. 测试基本运动
   └─> 是否震荡？
       ├─ 是 → 降低 Kp，增大 Kd
       └─ 否 → 继续

3. 测试响应速度
   └─> 是否太慢？
       ├─ 是 → 增大 Kp
       └─ 否 → 继续

4. 测试柔顺性
   └─> 接触力是否过大？
       ├─ 是 → 降低 Kp
       └─ 否 → 完成

5. 微调优化
   └─> 根据实际应用场景精细调整
```

## 💡 最佳实践

### 1. 使用阻尼模式（v_des = 0）

```python
# 推荐
controller.use_velocity_control = False
```

### 2. 根据场景选择模式

```python
# 接近物体：柔顺模式
controller.mit_control_all_joints(target_positions, mode='compliant')

# 快速运动：刚性模式
controller.mit_control_all_joints(target_positions, mode='stiff')

# 接触保护：阻尼模式
controller.mit_control_all_joints(target_positions, mode='damping')
```

### 3. 逐步增大 Kp

```python
# 从小参数开始
initial_kp_123 = 3.0
initial_kp_456 = 5.0

# 测试稳定后逐步增大
for kp_multiplier in [1.0, 1.2, 1.5, 1.8, 2.0]:
    kp_123 = initial_kp_123 * kp_multiplier
    kp_456 = initial_kp_456 * kp_multiplier
    # 测试...
```
