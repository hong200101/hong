## 💻 代码速查

### 基本控制

```python
import rclpy
import moveit_commander
import sys

# 初始化
rclpy.init()
moveit_commander.roscpp_initialize(sys.argv)
arm_group = moveit_commander.MoveGroupCommander('arm')

# 回到零位
arm_group.set_named_target('home')
arm_group.go(wait=True)

# 关节控制（Piper 6轴，单位：弧度）
arm_group.set_joint_value_target([0.0, 0.4, -0.6, 0.0, 0.0, 0.0])
arm_group.go(wait=True)

# 笛卡尔控制
from geometry_msgs.msg import Pose
target = Pose()
target.position.x = 0.3
target.position.y = 0.0
target.position.z = 0.3
target.orientation.w = 1.0
arm_group.set_pose_target(target)
arm_group.go(wait=True)

# 清理
moveit_commander.roscpp_shutdown()
rclpy.shutdown()
```

### 夹爪控制

```python
from sensor_msgs.msg import JointState

# 创建发布者
gripper_pub = node.create_publisher(JointState, '/control/joint_states', 10)

# 打开夹爪
msg = JointState()
msg.name = ['gripper']
msg.position = [0.08]  # 8cm
msg.effort = [1.0]     # 1N
gripper_pub.publish(msg)

# 关闭夹爪
msg.position = [0.0]   # 0cm
msg.effort = [2.0]     # 2N
gripper_pub.publish(msg)
```

### 笛卡尔路径

```python
from geometry_msgs.msg import Pose

# 定义路径点
waypoints = []
for i in range(4):
    pose = Pose()
    pose.position.x = 0.3
    pose.position.y = 0.1 * i
    pose.position.z = 0.3
    pose.orientation.w = 1.0
    waypoints.append(pose)

# 规划路径
(plan, fraction) = arm_group.compute_cartesian_path(
    waypoints,
    0.01,  # eef_step
    0.0    # jump_threshold
)

# 执行路径
if fraction > 0.95:
    arm_group.execute(plan, wait=True)
```

## 📊 参数速查表

### 机型参数

| 机型 | arm_type | 关节数 |
|------|----------|--------|
| Piper | piper | 6 |
| Piper X | piper_x | 6 |
| Piper H | piper_h | 6 |
| Piper L | piper_l | 6 |
| Nero | nero | 7 |

### 末端执行器

| 类型 | effector_type | 额外参数 |
|------|---------------|----------|
| 无 | none | - |
| 夹爪 | agx_gripper | - |
| Revo2 | revo2 | revo2_type:=left/right |
| Revo2 Pro | revo2_pro | revo2_type:=left/right |
| Revo2 Touch | revo2_touch | revo2_type:=left/right |

### 夹爪参数

| 参数 | 最小值 | 最大值 | 单位 | 推荐值 |
|------|--------|--------|------|--------|
| width | 0.0 | 0.1 | 米 | 0.05 |
| force | 0.5 | 3.0 | 牛顿 | 1.0-2.0 |

### 运动参数

| 参数 | 范围 | 推荐值 | 说明 |
|------|------|--------|------|
| 速度比例 | 0.0-1.0 | 0.2-0.3 | 首次运行用低速 |
| 加速度比例 | 0.0-1.0 | 0.2-0.3 | 与速度保持一致 |
| 规划时间 | 5-30秒 | 10秒 | 复杂任务可增加 |
| 位置容差 | 0.001-0.05米 | 0.01米 | 1cm |
| 姿态容差 | 0.01-0.1弧度 | 0.05弧度 | 约3度 |

### 出问题时
1. 立即按急停
2. 检查终端错误信息
3. 查看 `/feedback/arm_status`
4. 失能后重新使能

## 🆘 快速故障排除

| 问题 | 解决方案 |
|------|----------|
| 找不到 moveit_commander | `sudo apt install ros-$ROS_DISTRO-moveit*` |
| 机械臂不动 | 检查使能状态和控制门 |
| 规划失败 | 降低速度，增加规划时间 |
| 夹爪不工作 | 确认 `effector_type:=agx_gripper` |
| LC_NUMERIC 错误 | `export LC_NUMERIC=en_US.UTF-8` |
