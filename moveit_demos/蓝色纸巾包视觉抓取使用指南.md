## 1. 系统简介

本系统实现了基于 RealSense D435 相机的蓝色纸巾包视觉抓取功能，具有以下特点：

### ✨ 核心功能

- 🎯 **智能视觉识别**: 基于 HSV 颜色空间的蓝色物体检测
- 📐 **3D 定位**: 融合 RGB 和深度信息，精确定位物体 3D 坐标
- 🎮 **混合控制**: MoveIt 粗定位 + MIT 模式柔顺精调
- 🤲 **自适应抓取**: 根据物体位置自动规划抓取轨迹
- 🛡️ **安全可靠**: 工作空间限制、碰撞检测、柔顺控制

### 🔄 工作流程

```
视觉检测 → 坐标转换 → 抓取规划 → MoveIt接近 → MIT柔顺下降 → 夹爪抓取 → 撤退
```

## 2. 系统架构

### 2.1 模块组成

```
blue_tissue_grasp.py           # 主程序（系统集成）
├── vision_module.py           # 视觉模块（相机 + 检测）
├── grasp_planner.py          # 规划模块（位姿计算）
└── hybrid_controller.py      # 控制模块（MoveIt + MIT）
```

### 2.2 数据流

```
┌────────────────┐
│ RealSense D435 │
│   相机输入      │
└───────┬────────┘
        │ RGB + Depth
        ▼
┌────────────────┐
│   视觉处理      │  → 蓝色物体检测
│ vision_module  │  → 3D 位置提取
└───────┬────────┘
        │ (x_cam, y_cam, z_cam)
        ▼
┌────────────────┐
│   抓取规划      │  → 坐标转换（相机→基座）
│ grasp_planner  │  → 计算抓取位姿
└───────┬────────┘  → 生成轨迹（接近/抓取/撤退）
        │ GraspPose
        ▼
┌────────────────┐
│   混合控制      │  → MoveIt 粗定位
│hybrid_controller│ → MIT 柔顺精调
└───────┬────────┘  → 夹爪控制
        │
        ▼
    机械臂执行
```

## 5. 相机标定

### 5.1 为什么需要标定？

相机坐标系和机械臂基座坐标系不同，需要标定两者之间的变换关系。

```
       相机坐标系 (Camera Frame)
              Z (深度)
              ↑
              │
              └──→ X
             ╱
            ↙ Y

       基座坐标系 (Base Frame)
              Z (向上)
              ↑
              │
              └──→ X
             ╱
            ↙ Y
```

### 5.2 手眼标定方法

#### 方法 1: 手动测量（快速但不精确）

1. 测量相机在基座坐标系中的位置 (x, y, z)
2. 测量相机的姿态（通常向下看: pitch = π）
3. 更新配置文件 `camera_calibration` 部分

```yaml
camera_calibration:
  position: [0.4, 0.0, 0.5]           # 测量值（米）
  orientation: [0.0, 3.14159, 0.0]    # 相机朝下
```

#### 方法 2: 使用标定板（精确）

```bash
# 1. 安装 easy_handeye（ROS2 手眼标定工具）
sudo apt install ros-$ROS_DISTRO-easy-handeye

# 2. 打印 ArUco 标定板
# 参考: https://github.com/IFL-CAMP/easy_handeye

# 3. 运行标定
ros2 launch easy_handeye calibrate.launch.py

# 4. 采集多个标定点（建议 15+ 个）

# 5. 计算标定结果并更新配置文件
```

### 5.3 验证标定

运行测试程序验证坐标转换是否正确：

```bash
python3 blue_tissue_grasp.py --auto --visualize
```

观察机械臂是否能准确移动到检测物体的位置。如果偏差较大，需要重新标定。

## 6. 配置说明

### 6.1 配置文件位置

```
moveit_demos/config/blue_tissue_grasp_config.yaml
```

### 6.2 关键配置项

#### 视觉配置

```yaml
vision:
  # 蓝色HSV范围（需根据环境光照调整）
  blue_hsv_lower: [90, 50, 50]    # H:色调, S:饱和度, V:明度
  blue_hsv_upper: [130, 255, 255]
  
  min_area: 500  # 最小检测面积（像素），过滤噪声
```

**调整建议**:
- 光线充足时: 提高 V_min (如 100)
- 光线昏暗时: 降低 V_min (如 30)
- 蓝色偏青色: 降低 H_min (如 80)
- 蓝色偏紫色: 提高 H_max (如 140)

#### 抓取规划配置

```yaml
grasp:
  approach_distance: 0.15        # 接近距离（米）
  grasp_depth_offset: -0.05      # 抓取深度偏移（负值向上）
  
  workspace_limits:              # 工作空间限制
    x: [0.15, 0.6]
    y: [-0.4, 0.4]
    z: [0.0, 0.5]
```

#### MIT 控制参数

```yaml
control:
  mit_params:
    compliant:  # 柔顺模式（接近物体时使用）
      kp: 20.0  # 位置增益：越大越"硬"
      kd: 1.0   # 速度增益：越大越平滑
```

**参数调优**:
- 机械臂震荡 → 降低 `kp`，增大 `kd`
- 响应太慢 → 增大 `kp`
- 柔顺度不够 → 降低 `kp`

## 7. 快速开始

### 7.1 启动机械臂控制节点

**终端 1**:

```bash
cd ~/agx_arm_ws
source install/setup.bash

# 启动机械臂（带 MoveIt 和夹爪）
ros2 launch agx_arm_ctrl start_single_agx_arm_moveit.launch.py \
  can_port:=can0 \
  arm_type:=piper \
  effector_type:=agx_gripper
```

等待看到 `MoveIt is ready!` 提示。

### 7.2 运行视觉抓取系统

**终端 2**:

```bash
cd ~/agx_arm_ws/src/agx_arm_ros/moveit_demos

# 方式 1: 使用启动脚本（推荐）
chmod +x run_blue_tissue_grasp.sh
./run_blue_tissue_grasp.sh

# 方式 2: 直接运行 Python
python3 blue_tissue_grasp.py
```

### 7.3 交互式操作

系统启动后进入交互菜单：

```
======================================================================
请选择操作:
  1. 运行完整抓取循环（抓取后不放置）
  2. 运行完整抓取循环（抓取后放置）
  3. 仅检测目标
  4. 测试视觉系统
  5. 回零位
  6. 测试夹爪
  7. 重新加载配置
  0. 退出
======================================================================
```

**首次使用建议流程**:

1. 选择 `4` 测试视觉系统（调整蓝色检测参数）
2. 选择 `3` 检测目标（确认能检测到物体）
3. 选择 `5` 回零位（确认机械臂正常）
4. 选择 `6` 测试夹爪（确认夹爪正常）
5. 选择 `1` 运行完整抓取

## 9. 参数调优

### 9.1 视觉参数调优

#### 问题: 检测不到蓝色物体

**解决方案**:

1. 启动颜色校准工具:

```bash
python3 vision_module.py
# 按 'c' 进入校准模式
```

2. 调整滑动条，观察检测效果:
   - 增大检测范围: 降低 `S_min`, `V_min`
   - 缩小检测范围: 提高 `S_min`, `V_min`

3. 记录最佳参数并更新配置文件

#### 问题: 误检测太多

**解决方案**:

- 提高 `min_area` (如 1000)
- 缩小 HSV 范围

### 9.2 抓取规划调优

#### 问题: 物体在工作空间外

**解决方案**:

调整 `workspace_limits`:

```yaml
workspace_limits:
  x: [0.10, 0.7]   # 扩大 X 范围
  y: [-0.5, 0.5]   # 扩大 Y 范围
  z: [-0.05, 0.6]  # 扩大 Z 范围
```

#### 问题: 抓取位置不准

**解决方案**:

1. 检查相机标定是否准确
2. 调整 `grasp_depth_offset`:
   - 抓取位置太高 → 增大偏移值（如 -0.10）
   - 抓取位置太低 → 减小偏移值（如 0.00）

### 9.3 控制参数调优

#### 问题: MIT 模式下机械臂震荡

**解决方案**:

```yaml
control:
  mit_params:
    compliant:
      kp: 10.0   # 降低位置增益
      kd: 2.0    # 增大速度增益
```

#### 问题: 柔顺度不够（接触力太大）

**解决方案**:

```yaml
control:
  mit_params:
    compliant:
      kp: 5.0    # 进一步降低刚度
      kd: 1.0
```

#### 问题: 响应太慢

**解决方案**:

```yaml
control:
  mit_params:
    compliant:
      kp: 50.0   # 增大位置增益
      kd: 1.5
```

## 10. 常见问题

### Q1: 相机无法启动

**症状**: `相机启动失败`

**解决方案**:

```bash
# 1. 检查相机连接
rs-enumerate-devices

# 2. 检查权限
sudo chmod 777 /dev/video*

# 3. 重新插拔相机
```

### Q2: 检测不到蓝色物体

**症状**: `未检测到目标`

**可能原因**:
1. HSV 范围不正确
2. 光照条件变化
3. 物体面积太小

**解决方案**:
- 使用颜色校准工具调整 HSV 范围
- 改善光照条件
- 降低 `min_area`

### Q3: MoveIt 规划失败

**症状**: `✗ MoveIt 运动失败`

**可能原因**:
1. 目标位置不可达
2. 存在碰撞
3. 关节限位

**解决方案**:
- 调整目标位置
- 增大 `approach_distance`
- 检查工作空间限制

### Q4: 抓取位置偏移

**症状**: 机械臂移动到错误位置

**可能原因**: 相机标定不准确

**解决方案**:
1. 重新标定相机
2. 手动微调 `camera_calibration` 参数
3. 调整 `grasp_depth_offset`

### Q5: 夹爪无法抓紧

**症状**: 物体掉落

**解决方案**:

```yaml
control:
  gripper_grasp_width: 0.02   # 减小抓取宽度
  gripper_grasp_force: 2.5    # 增大抓取力
```

### Q6: MIT 模式无响应

**症状**: 柔顺下降阶段无动作

**可能原因**:
1. MIT 模式未启用
2. 关节索引错误
3. 固件版本不支持

**解决方案**:
- 检查固件版本（需 ≥ v1.8.8）
- 查看 `/feedback/arm_status` 确认模式

## 11. 高级功能

### 11.1 多物体抓取

修改主程序实现循环抓取:

```python
# 在 main() 中添加循环
for i in range(3):  # 抓取 3 个物体
    success = system.run_full_cycle(place_after_grasp=True)
    if not success:
        break
```

### 11.2 自定义抓取策略

编辑 `grasp_planner.py` 中的 `compute_grasp_pose()`:

```python
# 根据物体大小自适应夹爪宽度
width, height = self.estimate_object_size(...)
gripper_width = min(width + 0.02, 0.10)
```

### 11.3 添加力反馈

在 `hybrid_controller.py` 中添加力觉传感:

```python
# 检测接触力
if self.detect_contact():
    self.logger.info("检测到接触，停止下降")
    break
```

### 11.4 集成到 ROS2 节点

将主程序改造为 ROS2 服务:

```python
from example_interfaces.srv import Trigger

class GraspService(Node):
    def __init__(self):
        super().__init__('grasp_service')
        self.srv = self.create_service(
            Trigger, 'execute_grasp', self.grasp_callback
        )
    
    def grasp_callback(self, request, response):
        success = self.system.run_full_cycle()
        response.success = success
        return response
```
