🚀 快速开始（3 种方式）
--------------------------------------------------------------------------------

【方式 1】使用交互式启动脚本（最简单）
--------------------------------------

  arm_type:=piper use_sim:=true

# 终端 3: 启动 MoveIt
ros2 launch agx_arm_moveit demo.launch.py \
  arm_type:=piper use_sim_time:=true

# 终端 4: 运行 Demo

⚙️ 重要配置说明
--------------------------------------------------------------------------------

【必须设置】
use_sim_time:=true

这个参数非常重要！否则 Gazebo 仿真时间和 ROS2 时间不同步。

【可选配置】
- use_rviz:=true/false     # 是否启动 RViz
- gui:=true/false          # Gazebo GUI
- paused:=true/false       # 启动时暂停
- verbose:=true/false      # 详细日志

【示例】
# 完整可视化
ros2 launch agx_arm_moveit demo.launch.py \
  arm_type:=piper use_sim_time:=true

# 轻量级（无 RViz）
ros2 launch agx_arm_moveit demo.launch.py \
  arm_type:=piper use_sim_time:=true use_rviz:=false

# 服务器模式（无 GUI）
ros2 launch agx_arm_moveit demo.launch.py \
  arm_type:=piper use_sim_time:=true gui:=false

🆘 常见问题速查
--------------------------------------------------------------------------------

【Q1: Gazebo 启动很慢】
A: 首次运行会下载模型，需要等待。
   后续启动会快很多。
   使用：gazebo --verbose 查看进度

【Q2: 机械臂在 Gazebo 中掉落或抖动】
A: 控制器未正确加载
   检查：ros2 control list_controllers
   启动：ros2 control set_controller_state arm_controller start

【Q3: MoveIt 规划成功但不执行】
A: 确认设置了 use_sim_time:=true
   检查控制器连接

【Q4: 障碍物不显示】
A: 添加后等待场景更新
   使用：time.sleep(1.0)

【Q5: 性能问题/卡顿】
A: 关闭 RViz：use_rviz:=false
   降低更新频率：export GAZEBO_REAL_TIME_FACTOR=0.5
