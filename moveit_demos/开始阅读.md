## 🚀 三步开始

### 步骤 1: 准备环境

```bash
# 进入 demo 目录
cd ~/agx_arm_ws/src/agx_arm_ros/moveit_demos

# 安装依赖
pip3 install -r requirements.txt

# 添加执行权限
chmod +x *.py *.sh
```

### 步骤 2: 启动机械臂

**方式 A：使用快速启动脚本（推荐）**
```bash
./quick_start.sh
```
按照交互式提示选择配置即可！

**方式 B：手动启动**
```bash
# 真实机械臂 + MoveIt（Piper + 夹爪）
ros2 launch agx_arm_ctrl start_single_agx_arm_moveit.launch.py \
  can_port:=can0 arm_type:=piper effector_type:=agx_gripper

# 或仅 MoveIt 仿真（无需真机）
ros2 launch agx_arm_moveit demo.launch.py arm_type:=piper
```

### 步骤 3: 运行 Demo

打开新终端：
```bash
cd ~/agx_arm_ws/src/agx_arm_ros/moveit_demos
python3 moveit_simple_demo.py
```

## 🆘 遇到问题？

### 常见问题快速解决

**问题 1: 找不到 moveit_commander**
```bash
sudo apt install ros-$ROS_DISTRO-moveit*
source /opt/ros/$ROS_DISTRO/setup.bash
source ~/agx_arm_ws/install/setup.bash
```

**问题 2: 机械臂不动**
```bash
# 使能机械臂
ros2 service call /enable_agx_arm std_srvs/srv/SetBool "{data: true}"

# 打开控制门
ros2 service call /control_enable std_srvs/srv/SetBool "{data: true}"
```

**问题 3: 规划失败**
```python
# 降低速度和加速度
arm_group.set_max_velocity_scaling_factor(0.2)
arm_group.set_max_acceleration_scaling_factor(0.2)

# 增加规划时间
arm_group.set_planning_time(15.0)
```

**更多问题？**
- 查看 `使用指南.md` 的"常见问题解决"章节
- 查看 `README.md` 的"故障排除"部分
- 检查终端输出的错误信息
