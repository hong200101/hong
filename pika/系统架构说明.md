## 🎛️ 功能模块详解

### 模块 1: 设备配置 (选项 1-2)

```
输入: 物理设备
      │
      ├─ 检测 RealSense
      ├─ 检测 USB 串口
      ├─ 检测鱼眼相机
      └─ 检测 Vive Tracker
      │
输出: 配置文件
      │
      ├─ setup_*.bash (udev 规则)
      └─ start_*.bash (启动参数)
```

**关键技术**:
- `rs-enumerate-devices`: 检测 RealSense
- `lsusb`, `udevadm`: USB 设备管理
- `v4l2-ctl`: 视频设备检测

---

### 模块 2: 数据采集 (选项 3-9)

```
配置文件 ──▶ 启动脚本 ──▶ ROS2 Launch ──▶ 节点运行
                                          │
                         ┌────────────────┼────────────────┐
                         ▼                ▼                ▼
                    RGB Camera      USB Camera       Serial IMU
                         │                │                │
                         └────────────────┴────────────────┘
                                          │
                                     ROS2 Topics
```

**支持的模式**:
1. 单设备 (Sensor/Gripper)
2. 双设备 (双 Sensor/双 Gripper)
3. 混合 (Sensor + Gripper)
4. 头盔 (Helmet)
5. 完整 (双 Sensor + Helmet)

---

### 模块 3: 遥操作 (选项 10-11)

```
┌─────────────┐         ┌─────────────┐         ┌─────────────┐
│  Vive       │ 位姿数据 │  Pika       │ 控制指令 │  机械臂     │
│  Tracker    │ ──────▶ │  Sensor     │ ──────▶ │             │
└─────────────┘         └─────────────┘         └─────────────┘
      │                       │                       │
      └───────────────────────┴───────────────────────┘
                              │
                         采集并记录
```

**应用场景**:
- 实时遥操作控制
- 演示数据采集
- 人机协作

---

### 模块 4: 数据处理 (选项 12-15)

```
原始数据目录
  │
  ├─ camera/color/left/1234567890.123456.jpg
  ├─ camera/depth/left/1234567890.234567.png
  ├─ gripper/encoder/left/1234567890.345678.json
  └─ imu/9axis/left/1234567890.456789.json
  │
  │ [data_sync.py]
  │ 基于时间戳对齐
  │
  ├─ camera/color/left/sync.txt
  ├─ camera/depth/left/sync.txt
  ├─ gripper/encoder/left/sync.txt
  └─ imu/9axis/left/sync.txt
  │
  │ [data_to_hdf5.py]
  │ 转换为训练格式
  │
  └─ data.hdf5
      ├─ size: 1000
      ├─ timestamp: [t1, t2, ..., t1000]
      ├─ camera/color/left: [path1, path2, ...]
      ├─ gripper/encoderAngle/left: [a1, a2, ...]
      └─ imu/9axisOrientation/left: [[q1], [q2], ...]
```

**处理选项**:
- 单个 episode 处理
- 批量 episode 处理
- 索引模式（存路径）
- 数据模式（存实际数据）

## 🔐 安全与权限管理

```
┌─────────────────────────────────────────────────────────────┐
│                      权限层级                                 │
└─────────────────────────────────────────────────────────────┘

系统级 (需要 sudo)
  │
  ├─ udev 规则配置 (/etc/udev/rules.d/)
  ├─ USB 设备权限 (chmod 666 /dev/ttyUSB*)
  └─ 用户组管理 (usermod -a -G dialout)
  │
用户级 (普通用户)
  │
  ├─ ROS2 工作空间构建
  ├─ 脚本执行 (chmod +x)
  ├─ 数据记录和处理
  └─ 模型训练
```

**最小权限原则**:
- 配置阶段需要 `sudo`
- 运行阶段仅需普通权限
- 数据处理无需特殊权限

## 📊 性能指标

### 系统性能

| 指标 | 数值 | 说明 |
|------|------|------|
| 相机帧率 | 30 FPS | RGB + Depth |
| 鱼眼帧率 | 30 FPS | 超广角 |
| IMU 频率 | 100 Hz | 9轴传感器 |
| 夹爪频率 | 50 Hz | 编码器 |
| 数据同步精度 | ±50 ms | 可调 |
| HDF5 转换速度 | ~100 帧/秒 | 取决于硬件 |

### 资源占用

| 资源 | 单设备 | 双设备 |
|------|--------|--------|
| CPU | ~20% | ~35% |
| 内存 | ~500 MB | ~800 MB |
| USB 带宽 | ~300 Mbps | ~500 Mbps |
| 存储速度 | ~10 MB/s | ~18 MB/s |

## 🎯 设计理念

### 1. 用户友好
- 交互式菜单，无需记忆命令
- 彩色输出，清晰的状态反馈
- 智能错误处理和提示

### 2. 模块化
- 功能独立，易于维护
- 脚本解耦，便于扩展
- 文档分层，按需查阅

### 3. 容错性
- 设备检测和自动重试
- 优雅的错误处理
- 用户可选的强制执行

### 4. 可扩展
- 易于添加新设备类型
- 支持自定义数据处理
- 插件式架构

### 5. 高效性
- 批量处理节省时间
- 自动化流程减少错误
- 并行执行提高效率

## 📞 技术栈总结

### 语言与框架
- **Shell**: Bash 脚本
- **Python**: 3.10+
- **ROS2**: Humble
- **C++**: 用于性能关键节点

### 主要依赖
- **librealsense2**: RealSense SDK
- **OpenCV**: 图像处理
- **HDF5**: 数据存储
- **PyTorch**: 模型训练
- **libvive**: Vive Tracker（可选）

### 开发工具
- **colcon**: ROS2 构建工具
- **ament**: ROS2 包管理
- **git**: 版本控制
- **v4l-utils**: 视频设备管理
