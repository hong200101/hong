# 🎬 Pika Launcher 演示脚本

> 本文档提供完整的演示流程，适用于教学、培训和视频录制

---

## 📹 演示场景：双 Gripper 数据采集完整流程

**演示时长**: 约 10-15 分钟  
**难度级别**: ⭐⭐⭐☆☆ 中级  
**所需设备**: 2 个 Pika Gripper + 双臂机械臂

---

## 🎯 演示大纲

1. **环境准备** (2 分钟)
2. **设备配置** (3 分钟)
3. **启动采集** (2 分钟)
4. **数据记录** (3 分钟)
5. **数据处理** (3 分钟)
6. **结果验证** (2 分钟)

---

## 📝 详细演示步骤

### 第一幕：环境准备 (2 分钟)

#### 场景：打开终端，展示项目目录

```bash
# 讲解词
"大家好，今天我们演示如何使用 Pika Launcher 
进行双 Gripper 数据采集。首先，让我们进入项目目录。"

# 操作
cd ~/pika_ros-ros2
ls -la

# 讲解词
"这里可以看到 pika_launcher.bash 启动脚本，
以及相关的文档和配置文件。"

# 展示文件
tree -L 1

# 讲解词
"如果是首次使用，需要运行安装脚本来设置快捷命令。"

# 操作（演示用，实际已安装可跳过）
bash setup_launcher.bash

# 讲解词
"安装完成后，我们可以直接使用 'pika' 命令启动系统。"
```

---

### 第二幕：设备配置 (3 分钟)

#### 场景：运行 Launcher 并配置设备

```bash
# 操作
pika

# 讲解词
"系统启动后，我们看到一个交互式菜单。
菜单分为设备配置、数据采集、遥操作、数据处理和工具功能五大类。"

# 暂停展示菜单 (3 秒)

# 讲解词
"首次使用需要配置设备，我们选择选项 1。"

# 操作
输入: 1
按回车

# 讲解词
"这里会启动设备配置向导。我们需要选择设备类型。
今天演示双 Gripper 模式，所以输入 2。"

# 操作
输入: 2
按回车

# 讲解词
"现在系统提示我们插入左侧 Gripper。
注意，这里要确保插入到不同的 USB 端口。"

# 操作演示
[镜头切换到 USB 连接]
插入左 Gripper
按回车

# 讲解词
"系统正在检测设备信息，包括：
- RealSense 深度相机序列号
- USB 串口路径
- 鱼眼相机设备路径"

# 等待检测完成

# 讲解词
"左侧设备检测完成。现在需要拔出左 Gripper，
插入右侧 Gripper。注意不要插在同一个 USB 口。"

# 操作演示
[镜头切换]
拔出左 Gripper
插入右 Gripper 到另一个 USB 口
按回车

# 等待检测完成

# 讲解词
"系统生成了两个脚本文件：
- setup_multi_gripper.bash: 设备绑定规则
- start_multi_gripper.bash: 启动脚本
让我们验证一下绑定是否成功。"

# 操作演示
拔出右 Gripper
同时插入左右 Gripper
按回车等待验证

# 讲解词
"看到所有设备都检测通过了！配置完成。"

# 按任意键返回主菜单
```

---

### 第三幕：启动采集系统 (2 分钟)

#### 场景：启动双 Gripper 传感器节点

```bash
# 回到主菜单

# 讲解词
"配置完成后，我们可以启动数据采集系统了。
选择选项 6，启动双 Gripper 模式。"

# 操作
输入: 6
按回车

# 讲解词
"系统会先检查设备状态，确保所有硬件就绪。"

# 等待设备检查

# 讲解词
"检查通过！系统询问是否指定命名空间。
如果有多个机器人，可以用命名空间隔离 topics。
这里我们不使用命名空间。"

# 操作
输入: n
按回车

# 讲解词
"系统正在启动：
- 左右深度相机节点
- 左右鱼眼相机节点
- 左右串口通信节点（IMU + 夹爪）"

# 等待启动完成 (约 10 秒)

# 讲解词
"所有节点已启动！我们可以看到传感器数据正在发布。"

# [可选] 展示 topics
[新开终端展示]
ros2 topic list | grep gripper
ros2 topic hz /gripper/camera_l/color/image_raw
```

---

### 第四幕：数据记录 (3 分钟)

#### 场景：启动数据记录节点

```bash
# [新终端]

# 讲解词
"现在传感器已经运行，我们需要启动数据记录节点。
新开一个终端，加载 ROS2 环境。"

# 操作
cd ~/pika_ros-ros2
source install/setup.bash

# 讲解词
"使用 data_tools 包的 data_recorder 节点来记录数据。
指定输出目录为 ~/data/demo_episode。"

# 操作
ros2 run data_tools data_recorder \
  --output-dir ~/data/demo_episode \
  --config-type gripper

# 讲解词
"记录节点已启动，正在订阅所有传感器 topics。
现在可以开始操作任务了。"

# [镜头切换到机械臂]

# 讲解词
"我们演示一个简单的抓取任务：
1. 左臂移动到物体上方
2. 下降并抓取
3. 提升物体
4. 右臂接收物体
5. 放置到目标位置"

# [执行操作演示 - 约 30 秒]
[展示机械臂执行任务]

# 讲解词
"任务完成！现在停止数据记录。"

# 操作
按 Ctrl+C

# 讲解词
"数据已保存。我们可以看看采集了什么。"

# 操作
ls -lh ~/data/demo_episode

# 讲解词
"目录结构包括：
- camera/color: RGB 图像
- camera/depth: 深度图
- gripper/encoder: 夹爪状态
- imu/9axis: IMU 数据"

# 展示目录树
tree ~/data/demo_episode -L 3 | head -20
```

---

### 第五幕：数据处理 (3 分钟)

#### 场景：同步和转换数据

```bash
# [回到 launcher 终端]

# 讲解词
"采集完成后，需要对数据进行处理。
首先是数据同步，因为不同传感器频率不同。
选择选项 12。"

# 操作
输入: 12
按回车

# 讲解词
"输入数据集目录。"

# 操作
输入: ~/data
按回车

# 讲解词
"可以看到我们刚才采集的 demo_episode。
输入 episode 名称。"

# 操作
输入: demo_episode
按回车

# 讲解词
"选择数据类型为 gripper。"

# 操作
输入: gripper
按回车

# 讲解词
"时间差阈值使用默认的 0.05 秒。"

# 操作
按回车（使用默认值）

# 等待同步完成

# 讲解词
"数据同步完成！系统生成了 sync.txt 文件，
标记了时间对齐的数据帧。
接下来转换为 HDF5 训练格式。"

# 按任意键返回菜单

# 讲解词
"选择选项 13，数据转换。"

# 操作
输入: 13
按回车

# 按相同方式输入参数
数据集目录: ~/data
Episode 名称: demo_episode
数据类型: gripper
使用索引: y
包含点云: n

# 等待转换完成

# 讲解词
"转换完成！生成了 data.hdf5 文件。"

# 按任意键返回
```

---

### 第六幕：结果验证 (2 分钟)

#### 场景：加载并验证数据

```bash
# 在主菜单

# 讲解词
"最后，我们验证一下数据是否正确。
选择选项 14，数据加载示例。"

# 操作
输入: 14
按回车

# 输入参数
数据集目录: ~/data
Batch Size: 8

# 讲解词
"示例程序正在加载数据..."

# 观察输出

# 讲解词
"我们可以看到：
- 成功加载了 HDF5 文件
- 数据包含相机图像、夹爪状态、IMU 数据
- Batch 可以正常迭代
- 数据格式符合训练要求"

# 讲解词
"让我们看看实际的数据内容。"

# [可选：新终端展示]
python3 << EOF
import h5py
import numpy as np

with h5py.File('~/data/demo_episode/data.hdf5', 'r') as f:
    print("数据集大小:", f['size'][()])
    print("\n可用的数据类型:")
    for key in f.keys():
        print(f"  - {key}")
    
    print("\n左相机图像路径示例:")
    print(f['camera/color/left'][0].decode('utf-8'))
    
    print("\n左夹爪角度示例:")
    print(f['gripper/encoderAngle/left'][:5])
EOF

# 讲解词
"完美！数据已经准备好用于训练了。"
```
